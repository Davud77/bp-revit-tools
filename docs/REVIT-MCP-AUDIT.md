# Сравнение реализаций Revit MCP

Срез от 10 ноября 2026 года. Начальная точка — 100 команд BP.Revit.AI в Revit 2026. Сравнивались публичные реализации и спецификации популярных и функционально широких Revit MCP из [каталога](REVIT-MCP-CATALOG.md). Для открытых проектов ниже указаны проверенные файлы на зафиксированных коммитах. Для остальных указана доступная документация поставщика. Размер API измеряется по самостоятельным сценариям: `preview` и `apply` одной операции считаются одним сценарием, а различные режимы одного маршрутизатора учитываются по их фактическим возможностям.

## OOXGN

На `ee8f7e4` в регистрации Node MCP насчитано 89 уникальных команд. Все 89 совпали по имени с базовыми 100 командами BotPlus RT. В OOXGN нет 11 дополнительных команд BotPlus для переноса ресурсов оформления, инспекции семейства и чтения геометрии MEP-марок, позиционирования, объединения и дублирования типов. Механизмы локального моста и `preview → apply` имеют общую базу. Сравнение диспетчеров и транзакций не выявило отдельного рабочего сценария, который потребовал бы переноса в текущий модуль. [Регистрация OOXGN](https://github.com/OOXGN-OOX/RevitMCP/tree/ee8f7e4/server/src) · [Обработчики OOXGN](https://github.com/OOXGN-OOX/RevitMCP/tree/ee8f7e4/plugin/Bridge)


В NOTICE форка указан исходный коммит `c1bcd004c8fc690e901b831a72ec30268b28f66d`. В общий прогон BotPlus RT включены существующие тесты автоподтверждения: отсутствующие и повреждённые настройки, переключение режима, сохранение других полей и атомарная запись. Первый пакет добавил 10 MCP-имён для инвентаризации и спецификаций. `read_schedule` ограничивает страницу 50 строками и 20 столбцами и помечает усечённые ячейки через `truncatedCells`. `preview_schedule_fields` использует пробную транзакцию с полным откатом. [Схемы](../modules/codex-mcp/server/src/inventory-tools.js) · [Реализация](../modules/codex-mcp/plugin/Bridge/RevitTools.Inventory.cs)

Второй пакет добавил 41 имя, включая 12 пар `preview/apply`. Всего в исходниках 151 имя. Изменения модели идут через существующий план и транзакционный откат. Координаты геометрии передаются в метрах, координаты на листе — в миллиметрах, числовые фильтры спецификаций с видом `internalDouble` принимают внутренние единицы Revit. Проверка `bounds` возвращает кандидатов по габаритам. Режим `interference` следует правилам проверки Revit для элементов текущего документа. IFC выпускается во временной транзакции с откатом, DWG и IFC публикуются только после подтверждения выходных файлов. [Схемы](../modules/codex-mcp/server/src/extension-tools.js) · [Проверки](VALIDATION.md)

Code Mode вызывает доступные зарегистрированные команды через JavaScript. Сценарий может последовательно читать страницы и обрабатывать данные до возврата модели. Для записи Codex показывает и применяет отдельный проверенный план согласно правилам BP. Исполнение пользовательского C# или Python внутри Revit не входит в этот сценарий.
