# Установка BotPlus RT

1. Сохраните проекты и закройте Revit 2026.
2. Запустите `BotPlus.RT-<версия>-Setup.exe` из [Releases](https://github.com/Davud77/bp-revit-tools/releases) или локального каталога `Выходные данные/Установщики`.
3. Проверьте папку Revit. Если нужен перенос из Archicad, выберите версию Archicad 25–30 и её папку. По умолчанию выбран Archicad 28. Перед установкой Tapir закройте выбранный Archicad. Запись APX в Program Files может запросить права администратора. Если Archicad не используется, выберите «Не устанавливать Tapir».
4. Нажмите «Установить» и откройте Revit. Все модули BotPlus RT устанавливаются вместе. В **BotPlus RT → Настройки → Модули** снимите флажки с ненужных модулей, нажмите «ОК» и перезапустите Revit.

Установщик регистрирует одну надстройку для текущего пользователя. В EXE включены среда .NET для установщика, Node.js, MCP-сервер, Python с библиотеками IFC, Tapir 1.8.0 и ресурсы модулей. Журнал установки — `%LOCALAPPDATA%\BotPlus.RT\setup.log`.

## Размещение

| Что | Где |
| --- | --- |
| Приложение | `%LOCALAPPDATA%\BotPlus.RT\Application\versions\<версия>` |
| Манифест Revit | `%APPDATA%\Autodesk\Revit\Addins\2026\BotPlus.RT.addin` |
| Тема и модули | `%APPDATA%\BotPlus RT\settings.json` |
| Токен, настройки и снимки MCP | `%LOCALAPPDATA%\BP.Revit.AI` |
| Примеры подключения MCP | `connection` в папке установленной версии |
| Сеансы Ac2Revit | `%LOCALAPPDATA%\BotPlus.RT\Ac2Revit\sessions` |
| RVT Ac2Revit по умолчанию | `Документы\BotPlus.RT\Выходные данные` |
| Выгрузка ОВ | `Документы\RevitHeatLossExport` |

Установщик копирует семь шаблонов в `%ProgramData%\Autodesk\RVT 2026\Templates\Russian` и добавляет их в список «Новый проект» (Ctrl+N) под именами «ADSK АР», «ADSK ВК», «ADSK КЖ», «ADSK КМ», «ADSK ОВ», «ADSK СС» и «ADSK ЭОМ». Перед изменением он резервирует `Revit.ini`. При обновлении ссылки на эти семь файлов из «Входные данные\Шаблоны» и предыдущих версий BotPlus RT заменяются ссылками на общую папку Revit. При удалении плагина записи убираются из профиля текущего пользователя, общие файлы шаблонов остаются доступны другим профилям.

## Подключение MCP

Подключите Codex или Claude через **BotPlus RT → MCP → MCP**. Ключ подключения — `bp_revit_ai`. При обновлении установщик переводит существующее подключение BotPlus RT на новую версию и резервирует изменённые конфигурации. Автоподтверждение настраивается отдельно на панели MCP.

При переходе со сборки с прежним каталогом данных можно перенести `settings.json` и папку `snapshots` в `%LOCALAPPDATA%\BP.Revit.AI` перед первым запуском. При отсутствии токена Revit создаст его автоматически.

## Обновление и удаление

Для обновления запустите новый EXE или воспользуйтесь кнопкой **Настройки → Обновления**. Закройте Revit перед установкой. Если предыдущая версия занята MCP-клиентом, её папка будет удалена при следующей установке. Сеансы из старых папок версий архивируются в `saved-sessions`.

При переходе со старых отдельных надстроек установщик переименовывает их пользовательские манифесты и сохраняет оригиналы. Если отдельная надстройка зарегистрирована для всех пользователей, сначала удалите её через Windows. Если в одном манифесте перечислены BotPlus и сторонние надстройки, разделите его до установки.

Чтобы удалить BotPlus RT, закройте Revit и MCP-клиент и выберите BotPlus RT в «Установленных приложениях» Windows. Установщик удаляет свою запись MCP, архивирует сеансы, сохраняет проекты, выгрузки, настройки и токен. Старые манифесты восстанавливаются, если их имена свободны. Tapir остаётся в Archicad.

## Командная строка

Укажите имя загруженного EXE. Ниже пример для 1.9.6.

```powershell
$setup = '.\BotPlus.RT-1.9.6-Setup.exe'
& $setup --silent
& $setup --silent --revit="D:\Autodesk\Revit 2026"
& $setup --silent --tapir=29 --archicad="D:\Graphisoft\Archicad 29"
& $setup --silent --no-tapir
& $setup --uninstall
& $setup --silent --verify-payload="D:\empty-test-folder"
```

`--verify-payload` распаковывает и проверяет файлы в пустой папке. Установка, регистрация надстройки и подключение клиентов при этом не выполняются.
