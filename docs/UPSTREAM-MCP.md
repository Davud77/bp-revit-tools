# Сравнение с OOXGN RevitMCP

Проверено 02.11.2026: [OOXGN-OOX/RevitMCP](https://github.com/OOXGN-OOX/RevitMCP), commit `ee8f7e4` (initial release 0.0.1). В NOTICE форка исходной базой указан Davud77/WEAM.Revit.AI `c1bcd004c8fc690e901b831a72ec30268b28f66d`. Сравнивались реализации `plugin/Bridge`, `ApprovalSettings`, `server/src`, тесты и описание поставки, с учётом переименования namespace и идентификаторов.

## Что перенесено

В форке `tests/ApprovalSettings.Tests` включён в проверку поставки. Такая проверка уже есть в нашем исходном MCP, но ранее не входила в общий прогон BotPlus RT. Теперь она включена в `scripts/test.ps1`: отсутствующий/повреждённый файл, недопустимый тип флага, включение/выключение без перезапуска, сохранение посторонних настроек и очистка временного файла атомарной записи. Она работает с нашим неизменённым `WEAM.Revit.AI/settings.json`.

Исходный код теста совпадает с нашим после переименования namespace; перенос другой копии не нужен. Сравнивался [Program.cs форка](https://github.com/OOXGN-OOX/RevitMCP/blob/ee8f7e4/tests/ApprovalSettings.Tests/Program.cs). Лицензия обоих проектов AGPL-3.0-only. Брендинг и товарные знаки OOXGN не переносились. Отдельных новых геометрических возможностей, превосходящих нашу текущую реализацию, в проверенном снимке не обнаружено.

## Что не является улучшением нашего кода

- `ApprovalSettings` функционально совпадает с нашим вариантом; заменять рабочую реализацию другой копией не требуется.
- Основные геометрические адаптеры имеют общее происхождение. В проверенном форке отсутствует часть наших дополнительных операций документации и MEP-марок.
- В `Operations` форк удаляет закрытый Document через Dictionary.Remove; у нас уже есть исправление исключения native GetHashCode закрытого документа с пересозданием словаря живых документов. Откат не переносится.
- У форка другие порт, имя MCP, namespace и каталог данных. Наши контракты, порт 37651, ключ `weam_revit_ai` и каталог WEAM.Revit.AI сохраняются.
- Независимый установщик/CI форка и оформление релизов полезны как образец. Перенос автоматического выпуска EXE всего BotPlus RT требует объединённой CI-сборки трёх модулей и разрешённых ресурсов; добавлен в дорожную карту.

По поиску публичных репозиториев `user:OOXGN-OOX MCP` найден RevitMCP. Новые серверы могут появиться позднее. Для этого чата настроена еженедельная проверка по понедельникам в 10:00; кандидаты добавляются в дорожную карту после сравнения кода, лицензии и способа проверки. Фоновая проверка не устанавливает DLL и не изменяет пользовательские модели.
