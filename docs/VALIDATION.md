- Короче папки этапов: `prep-ГГГГММДД-ччммсс` и `run-ГГГГММДД-ччммсс`, с суффиксом при совпадении.

Связь задания с коммуникацией и основой сохраняется в RVT, с отдельной идентичностью каждого экземпляра связи. Уровень локального задания берётся от основы. Зазор задаётся на сторону, наружный диаметр труб/коробов берётся отдельно от номинального; учитываются внешняя изоляция, ориентация профиля и смещение при проходе через всю толщину. Для больших проектов ограничены число MEP и число пар габаритов, рекомендована выбранная область. Габариты основ вычисляются один раз за поиск.

Полный scripts/test.ps1 прошёл, включая новую проверку нормального круглого прохода с изоляцией, косого прямоугольного прохода, наклонного круглого профиля через перекрытие, отключения изоляции, некорректных базисов/зазоров и идентичности двух экземпляров связи. Журнал — «Выходные данные/Проверки/openings-162-tests-final.log». Сборка без предупреждений и ошибок.

Найден центр прохода X=10000, Y=12500 мм, создано пятое задание к связанной основе; при отключении связей этот проход не попадает в поиск.
