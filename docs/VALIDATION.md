Фактическая проверка 02.11.2026 на открытом исходном PLN Каспийска, Archicad 28 / Tapir 1.7:

- Полный новый комбинированный сеанс дошёл до статуса `ready` и `pipeline.json`: 1253 исходных элемента, JSON, IFC, исходные границы, проверка источника и подготовка геометрических этапов. Лог: `local/validation/combined-1.2.0-live.log`.

- Сборка всех модулей: 0 ошибок, 0 предупреждений. Общий прогон: 139 Python-тестов Ac2Revit, C#-контракты (включая запрет возврата исключённых зависимостей), 11 проверок настроек MCP, 24 теста MCP, 5 проверок конфигураций, жизненный цикл хоста и проверки ОВ. Сохраняются ограничения кровель, подрезок стен и сложных проёмов из аудита Каспийска.

Изменения установленных DLL, RVT и PLN во время этой проверки не выполнялись.

## Диагностика отказа IFC из активного окна

По журналу пользовательского сеанса 02.11.2026 код `-2130313109` расшифрован как `APIERR_BADWINDOW`: текущий контекст окна Archicad не допускает сохранение IFC. Источник: [Graphisoft Error Codes](https://archicadapi.graphisoft.com/documentation/error-codes). В исходниках клиент API сохраняет структурированные код и команду ошибки; рабочий процесс предлагает открыть план этажа и восстановить сохранённый сеанс через `session.json`. Другие команды и коды не получают эту подсказку. Тесты проверяют реальный формат ответа Tapir, сохранение кода и выбор диагностического сообщения. Натурный повтор экспорта не выполнен: Archicad и Revit на момент проверки закрыты. Изменение пока в исходниках; установщик 1.1.0 не пересобирался.

## Изменения 1.1.0

Добавлены «Сервис» с версией сборки, читаемые имена вместо генерируемых хешей и GUID в марках, адаптер Mesh → Toposolid и явные верхние ограничения помещений. Общая сборка и существующий автоматический прогон прошли. Новый Toposolid-адаптер и установка 1.1.0 в живом Revit ещё не проверены: это предварительная интеграционная сборка. Адаптер отклоняет неподдерживаемый рельеф и несовпадение контрольных точек поверхности, сохраняет контуры с отверстиями. Проверка точек не является доказательством равенства всей поверхности.

В текущем PLN через Tapir 1.7 и встроенные свойства Archicad прочитаны ограничения всех 110 зон. Верхний этаж проверяется независимо по относительному индексу и абсолютной отметке с верхним смещением. Неизвестная локализованная связь не выдаётся за подтверждённую. Добавлены 8 проверок высот и противоречивых ограничений; всего 129 Python-тестов. Применение этих ограничений в новой модели Revit ещё не проверено. Аудит сохранённого RVT описан в [KASPIYSK-AUDIT.md](KASPIYSK-AUDIT.md); исправления кровли/проёмов этим аудитом не подтверждаются.

EXE 1.1.0 распакован собственной командой `--verify-payload`; проверены SHA-256 4126 файлов и протокольный запуск MCP. Финальная сборка с извлечением ограничений зон проверяется теми же командами. Установка в пользовательский Revit этим не подтверждается.

Запуск: `scripts/test.ps1 -BuildPython <путь-к-python.exe>`.

Проверки объединённой поставки: сборка хоста и трёх модулей, порядок запуска/остановки и очистка при частичном сбое хоста, существующие тесты MCP и редактора конфигураций, Python unit tests Ac2Revit, C# contract checks, независимые проверки экспорта ОВ, расчёта и радиаторов. Исторические браузерные проверки в `modules/ov/tests/*checks.cjs` требуют отдельно установленного Playwright; часть из них рассчитана на конкретный частный экспорт и в стандартный прогон не включена.

Фактический прогон 02.11.2026: общая сборка — 0 ошибок и 0 предупреждений; 2 проверки жизненного цикла хоста; MCP — 24 теста; редактор конфигураций — 5 тестов; Ac2Revit — 121 Python-тест и C#-контракты; ОВ — проверки геометрического контракта, защиты HTML, расчёта теплопотерь и подбора радиаторов. EXE 1.0.0 распакован собственной командой проверки с exit 0; поставляемый Python запускается из новой папки и загружает ifcopenshell 0.8.5, NumPy 2.5.4, Shapely 2.2.0 без старой виртуальной среды.

Повторяемая проверка распакованной поставки: `node scripts/verify-payload.mjs <папка-распаковки>` — SHA-256 всех файлов release.json и протокольный запуск MCP со списком инструментов, без подключения к модели.

Для готового EXE дополнительно проверяются распаковка через `--verify-payload`, контрольные суммы файлов, изоляция Python от исходной среды, загрузка IFC/NumPy/Shapely, запуск поставляемого MCP-сервера и отсутствие Autodesk API, частных моделей и секретов. Фактические результаты текущей проверки сохраняются в `local/validation`.

Сборка и автоматические тесты не подтверждают загрузку ленты в живом Revit, полный экспорт PLN и инженерную приёмку модели. До такой проверки версия считается предварительной интеграционной поставкой. Пользовательские RVT и PLN во время переноса не редактируются.
