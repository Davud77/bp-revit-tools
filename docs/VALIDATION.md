# Проверки

Запуск: `scripts/test.ps1 -BuildPython <путь-к-python.exe>`.

Проверки объединённой поставки: сборка хоста и трёх модулей, порядок запуска/остановки и очистка при частичном сбое хоста, существующие тесты MCP и редактора конфигураций, Python unit tests Ac2Revit, C# contract checks, независимые проверки экспорта ОВ, расчёта и радиаторов. Исторические браузерные проверки в `modules/ov/tests/*checks.cjs` требуют отдельно установленного Playwright; часть из них рассчитана на конкретный частный экспорт и в стандартный прогон не включена.

Фактический прогон 02.11.2026: общая сборка — 0 ошибок и 0 предупреждений; 2 проверки жизненного цикла хоста; MCP — 24 теста; редактор конфигураций — 5 тестов; Ac2Revit — 121 Python-тест и C#-контракты; ОВ — проверки геометрического контракта, защиты HTML, расчёта теплопотерь и подбора радиаторов. EXE 1.0.0 распакован собственной командой проверки с exit 0; поставляемый Python запускается из новой папки и загружает ifcopenshell 0.8.5, NumPy 2.5.4, Shapely 2.2.0 без старой виртуальной среды.

Повторяемая проверка распакованной поставки: `node scripts/verify-payload.mjs <папка-распаковки>` — SHA-256 всех файлов release.json и протокольный запуск MCP со списком инструментов, без подключения к модели.

Для готового EXE дополнительно проверяются распаковка через `--verify-payload`, контрольные суммы файлов, изоляция Python от исходной среды, загрузка IFC/NumPy/Shapely, запуск поставляемого MCP-сервера и отсутствие Autodesk API, частных моделей и секретов. Фактические результаты текущей проверки сохраняются в `local/validation`.

Сборка и автоматические тесты не подтверждают загрузку ленты в живом Revit, полный экспорт PLN и инженерную приёмку модели. До такой проверки версия считается предварительной интеграционной поставкой. Пользовательские RVT и PLN во время переноса не редактируются.
