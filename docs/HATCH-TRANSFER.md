# Перенос штриховок материалов

Основной шаблон по указанию пользователя: локальный `ADSK_RU_ШаблонПроекта_АР_r2021_v2.2.1.rte` из папки «Входные данные». Путь сохранён в пользовательских настройках `%LOCALAPPDATA%/BotPlus.RT/Ac2Revit/settings.json`; сам шаблон в Git и поставку не включается. Revit 2026 читает проверочную копию шаблона и обновляет создаваемый проект, исходный RTE не перезаписывается.

Правила выбираются по назначенной исходной штриховке, а не по догадке из имени строительного материала. Изучены каталоги десяти различных исходных проектов, включая 64–865 материалов. Общие группы: бетон / железобетон, кладка, древесина / фанера, утеплитель, гидроизоляция, металл, песок / грунт, отделка. Для составных символов каркаса с заполнением применяется явный условный аналог; детали каркаса таким рисунком не воспроизводятся.

Порядок выбора:

- Указанный ADSK-образец, если он присутствует в шаблоне.
- Явно перечисленный нативный аналог текущего шаблона.
- Для Vector — новый нативный Drafting FillPattern из исходных семейств линий, шага, угла, смещения и пар штрих / пробел.
- Для известных Symbol — явно заданный переносимый условный аналог, если нужных образцов в шаблоне нет. Неизвестный символ остаётся в отчёте несопоставленным.

Пустая заливка очищает рисунок; только исходные 100% Solid получают сплошную заливку. Сохраняются передний цвет и положительное фоновое перо активной таблицы Archicad. Процентные заливки получают обозначенный аналог, без утверждения о точном сохранении плотности.

Определения новых образцов проверяются чтением Revit. Существующие одноимённые изменённые образцы блокируют применение. Проверяется предыдущее состояние импортированных материалов, чужие материалы не перезаписываются. Новые определения и назначения входят в одну откатываемую группу транзакций. Повторный запуск не создаёт новые образцы.

Ограничения: речь о графике среза строительных материалов. Фазировка относительно элемента и FitToSkin Archicad не воспроизводятся. Масштабируемые в модели векторные образцы фиксируются как Drafting для явного масштаба 1:100, указанного в правилах. Symbol-аналоги не являются копией исходных дуг и деталей. Отдельные 2D-заливки чертежей, текстуры и грани импортированных тел без исходного строительного материала требуют отдельного покрытия; полная визуальная приёмка всех конструкций ещё не выполнена.

Основания преобразования: [Graphisoft API_FillLine](https://archicadapi.graphisoft.com/documentation/api_fillline), [Graphisoft API_FilltypeType](https://archicadapi.graphisoft.com/documentation/api_filltypetype), [Autodesk FillGrid](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API-MainReference/files/html/6dfc3e2f-c869-d06e-876e-49c4007f7e59.htm). Фактические углы API проверены чтением нативных образцов; длины передаются во внутренних футах.

Проверки 04.11.2026: на указанном ADSK-шаблоне 64/64 материала Каспийска, затем 865/865 расширенного каталога. На стандартном русском шаблоне также 865/865. Во всех трёх случаях пройдены назначение, повторный запуск с unchanged и аудит после сохранения / закрытия / открытия RVT. Расширенный ADSK-каталог: 596 аналогов, 173 пустых, 2 сплошных, 34 исходных векторных, 60 переносимых аналогов. В стандартном шаблоне: 626 аналогов, 173 пустых, 2 сплошных, 64 векторных. Это проверки определений и назначений, а не визуальная сверка каждого элемента модели.

Локальные артефакты: `Выходные данные/Проверки/hatches-20261104/ten-projects-standard-template.json`, `tests.log`; нативные проверки — `Выходные данные/Проверки/kaspiysk-comparison-20261103/native/modules/ac2revit/artifacts/hatches-*-20261104/`. Они не включаются в поставку.


## Штриховки отдельных элементов — продолжение 04.11.2026

В общий pipeline после создания планов добавлен этап `elementHatches`. Строительные материалы слоёв не заменяются. Нативный OverrideGraphicSettings задаёт только рисунок и цвета выбранного канала: поверхность для плана перекрытия либо срез для объекта. Остальные переопределения вида сохраняются. План назначений привязан к SHA-256 исходного manifest и проверяет исходный GUID элемента, его тип, этаж и идентичность штриховки.

Поддержаны включённый `Slab.floorFill` с глобальной единичной матрицей и нулевым началом, а также явные атрибуты среза Object / Lamp при `useObjectSectionAttributes=false`. Для перекрытий назначение действует на планах собственного исходного этажа. Поворот, деформация, другое начало и получение рисунка из покрытия пока выдаются как неподдержанные. Переопределения перьев среза составной конструкции не превращаются в одну общую заливку. Старый снимок без полного каталога штриховок / активных перьев сохраняет прежнюю графику и получает явное ограничение вместо остановки всего переноса.

По [схеме Tapir](https://enzyme-apd.github.io/tapir-archicad-automation/archicad-addon/), флаг `useObjectSectionAttributes=true` означает использование атрибутов внутри библиотечной части вместо полей sectionFillId / sectionFillPen. Поэтому эти поля не используются как будто они задают фактический срез GDL. В текущем снимке Каспийска таких объектов 93; внутренних назначений в нём нет. Для их поддержки требуется достоверный снимок вычисленной графики библиотечной части и сопоставление её частей геометрии, а не правило по названию объекта. Отдельные 2D-заливки и прочие ранее указанные ограничения также остаются.

Проверенный результат: 80 перекрытий имеют включённый исходный floorFill «25 %»; 73 объекта явно используют Empty в срезе. Подготовлены все 153 назначения, Revit прочитал обратно 1321 переопределение по видам. Все повторные назначения unchanged, графика сохранилась после закрытия и открытия RVT. Отдельная ручная правка цвета вызвала conflict и не была перезаписана. Процентный рисунок остаётся явно обозначенным аналогом; плотность 25% не заявляется точно сохранённой.

На исходном ADSK_RU_ШаблонПроекта_АР_r2021_v2.2.1.rte создан новый проверочный проект с 64 нативными стенами-образцами срезов и подписями. Рисунки отрисованы Revit и осмотрены; назначения 64/64 повторно проверены после сохранения / открытия. Это визуальная проверка образцов материалов, а не приёмка всех конструкций здания в сравнении с Archicad.

Артефакты находятся физически в «Выходные данные/Проверки/kaspiysk-comparison-20261103/native/modules/ac2revit/artifacts»:

- `hatches-elements-final-20261104/result.json`: повтор, сохранение ручной правки и повторное открытие.
- `hatches-elements-final-20261104/audit.json`: назначения по GUID / элементу / виду, отдельные ограничения GDL.
- `hatches-elements-final-20261104/hatches-elements.rvt`: проверочная копия здания.
- `hatches-visual-adsk-final-20261104`: RVT образцов, PNG всех 64 материалов и аудит после открытия.
- Общие тесты: «Выходные данные/Проверки/hatches-20261104/element-tests.log».

Исходный RTE и пользовательские PLN / RVT не изменялись. Диагностическая регистрация временно использовала единственный BotPlus.RT.addin; затем восстановлена побайтно. Установленная 1.6.1 остаётся прежней поставкой; новое расширение находится в исходниках и проверочной сборке, новый релиз не публиковался. Общий пункт «Перенос штриховок» остаётся невыполненным до расширения покрытия и визуального сопоставления остальных конструкций.
