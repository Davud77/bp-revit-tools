# Входные, выходные данные и исходники плагина

В корне находятся исходники плагина и две физические папки данных. Совместимые junction, символические и жёсткие ссылки прежнего размещения удалены. Частные данные целиком исключены из Git и поставки.

| Каталог | Содержимое |
| --- | --- |
| `Входные данные/` | Пользовательские PLN / RVT / PDF, частные шаблоны и примеры |
| `Входные данные/Первоначальный архив/` | Первоначальные рабочие папки с историей; архив не редактируется и не публикуется |
| `Входные данные/Исходники upstream/` | Исходники для локального сравнения |
| `Выходные данные/Установщики/` | Готовые EXE, соответствующие исходники ZIP и SHA256SUMS |
| `Выходные данные/Сборочные данные/dotnet/` | DLL, obj и результаты публикации .NET, раздельно по проектам |
| `Выходные данные/Сборочные данные/tapir/` | Проверенный кеш официальных APX для сборки |
| `Выходные данные/Проверки/` | Натурные модели, снимки, журналы и отчёты тестов |
| `Выходные данные/Проверки ОВ/` | Результаты автоматических проверок ОВ |
| `Выходные данные/Отчёты просмотрщика/` | Проверочные отчёты просмотрщика |
| `Выходные данные/Локальные инструменты/gh/` | GitHub CLI для публикации релизов (не входит в поставку) |

Во входных данных хранятся только исходные материалы: PLN, шаблон ADSK, референсы BimStep / ОВ, исходники upstream и первоначальный архив (исходники, история Git, Python-среда сборки `.ifc-env`, Poteri). Регенерируемые результаты прежних запусков в архив не помещаются. В «Проверках» сохраняются итоговые протоколы, на которые ссылаются VALIDATION.md и тематические документы. Промежуточные попытки (r1…rN), распакованные копии поставки и копии исходных PLN после проверки удаляются.

`src`, `modules`, `installer`, `scripts`, `tests`, `docs` и корневые файлы проекта содержат разрабатываемый плагин, тесты и документацию. В установщик попадает явный состав из `scripts/package.mjs`; исходники ZIP берутся из Git с исключениями `.gitignore`. Частные модели, Autodesk API и токены проверяются при упаковке. Четыре штатных RFA/RFT Ac2Revit разрешены.

`Directory.Build.props` направляет результаты .NET в выходную папку. `build-installer.ps1` использует прямой путь к локальной Python-среде из входного архива; другой путь задаётся `-BuildPython`. Временная папка упаковки удаляется после завершения или ошибки. `scripts/clean.ps1 -Preview` показывает устаревшие промежуточные файлы, `scripts/clean.ps1` удаляет их; входные данные, установщики и доказательства проверок сохраняются. Зависимости Node.js управляются pnpm и не входят в Git.

Старые пути `local`, `dist`, `artifacts`, `output` больше не существуют. Исторические отчёты могут содержать эти пути как запись прежних запусков; текущие команды от них не зависят. Рабочие данные установленного Ac2Revit по-прежнему находятся в пользовательском каталоге BotPlus.RT, независимо от структуры исходников.
