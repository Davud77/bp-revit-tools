# Входные и выходные данные

Частные данные исключены из Git целиком, включая произвольные файлы внутри этих папок.

| Каталог в рабочем репозитории | Содержимое |
| --- | --- |
| `Входные данные/` | Пользовательские PLN / RVT / PDF, частные шаблоны, дополнительные примеры |
| `Входные данные/Первоначальный архив/` | Полный первоначальный архив Ac2Revit, HeatLossViewer и revit_mcp, включая историю и исходную Python-среду |
| `Входные данные/Исходники upstream/` | Локальные исходники для сравнения |
| `Выходные данные/Установщики/` | EXE, исходники ZIP, SHA256SUMS |
| `Выходные данные/Сборочные данные/` | Промежуточные поставки и кеш Tapir |
| `Выходные данные/Проверки/` | Диагностические модели, снимки, журналы, отчёты и копии поставок |
| `Выходные данные/Проверки ОВ/` | Результаты браузерных проверок просмотрщика |
| `Выходные данные/Локальные данные/` | Прежние распакованные поставки и вспомогательные данные миграции |
| `Выходные данные/Отчёты просмотрщика/` | Проверочные отчёты просмотрщика |

Прежние пути `local/…`, `dist/`, `artifacts/` и пути модулей сохраняются локальными ссылками NTFS. Это позволяет использовать существующие команды сборки, сохранённые сеансы и доказательства без переписывания их контрольных сумм. Ссылки и частные данные не входят в Git или установщик. Исходники модулей, тестовые сценарии и четыре разрешённых RFA/RFT остаются в `modules`.

Если исходный файл открыт приложением, Windows может запрещать перемещение его папки. До закрытия файла его исходное расположение сохраняется; незавершённые перемещения фиксируются в локальном `Выходные данные/Размещение архива.json`.
