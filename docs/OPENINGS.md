# Менеджер отверстий

В Revit откройте **BotPlus RT → Отверстия**. «Пересечения» открывает поиск, «Менеджер отверстий» — реестр того же проекта.

## Поиск и создание заданий

1. Выберите связи и при необходимости включите «Только выбранные MEP». Поиск проверяет открытую модель, затем выбранные связи по порядку. Без выбранных связей работает с открытой моделью.
2. В «Правилах» задайте запас для ширины, высоты и диаметра, округление, минимальный размер, глубину, изоляцию и склейку соседних отверстий. Правила хранятся в `%LOCALAPPDATA%\BotPlus.RT\Openings\settings.json`.
3. Нажмите «Найти пересечения». Таблица показывает связь, элементы, точку, предложенные размеры и состояние задания. Нажатие на «Коммуникация» выбирает коммуникацию, на «Основа» — основу, на другие ячейки — оба элемента. Во время поиска доступна отмена.
4. Выберите строки с новыми заданиями и нажмите «Создать выбранные задания». Для выбранной модели АР действует фильтр по основам. Без выбора модели АР этот фильтр отключён. Перед записью модуль повторяет поиск и отклоняет устаревшие строки.

Для отверстия нужен проход оси коммуникации через прямую стену или горизонтальное перекрытие. Коллизия «Сеть × сеть» определяется пересечением тел и отображается в таблице без создания отверстия. Подключённые элементы одной сети и простые касания исключаются. Вырезанный проход может исчезнуть из поиска, его задание остаётся в реестре.

## Реестр и согласование

В «Настройках» создать реестр и назначить роли по именам Windows. Первый создатель становится администратором. Настройки и каждое задание хранятся отдельно в Extensible Storage внутри RVT; изменения попадают в файл при сохранении проекта. Эти роли управляют действиями модуля, но не являются защитой RVT от внешнего редактирования.

В реестре доступны ручное создание по точке на прямой стене или перекрытии, прямоугольная и круглая форма, редактирование центра/размеров/глубины/угла, копирование по точке и уровням, объединение, логические шахты и выбор в модели или 3D. Маркеры — DirectShape; это задания, физические вырезы выполняются отдельной командой.

Согласования ИОС, АР и КР независимы. Только все три дают полный статус. Администратор выбирает роль согласования; остальные работают за свою роль. Изменения сравниваются с геометрией начала согласования, поэтому несколько малых перемещений не обходят допуск. Изменение сверх допуска требует причины и снимает согласования. Отказ требует комментария. Удаление создателем требует разрешений ранее согласовавших АР/КР; администратор может удалить напрямую. При существующих физических вырезах сначала требуется снять их.

История хранит автора, время, роль, действие, причину, ревизию и геометрию. При объединении сохраняется происхождение и история исходных заданий; архивирование не уничтожает события. Внешнее перемещение или удаление маркера обнаруживается по геометрическому отпечатку: согласования снимаются, статус требует проверки. Для восстановления задания нужно явно подтвердить геометрию через редактор.

Цвета обновляются на текущем виде: красный — без согласования текущей роли, жёлтый — согласовано этой ролью, зелёный — всеми, фиолетовый — запрос удаления. Поиск и сортировка работают в таблице; удалённые задания показываются отдельным флажком.

Обмен использует собственный JSON `botplus.openings/1` с миллиметрами во внутренних координатах модели либо реестр загруженной Revit-связи с её фактическим преобразованием. По умолчанию новые задания принимаются только полностью согласованными; отзыв согласований уже принятого задания также обновляется. Повторный импорт не дублирует задания, старые и конфликтующие ревизии пропускаются с сообщением. Полученные задания редактируются в исходной модели. JSON не выполняет автоматическое сопоставление общих координат; для разных систем координат следует использовать связь.

Команда вырезания доступна АР, КР и администратору для полностью согласованных заданий. Собственные пустотные семейства создаются из установленного стандартного шаблона Autodesk, отдельно для стены/перекрытия и формы. Шаблоны Autodesk не входят в поставку. Модуль проверяет пересечение, глубину, принадлежность семейства и совпадение геометрии результата с заданием; ошибочная транзакция откатывается. Повторный вырез без изменения задания не создаёт новую вставку. Чужое одноимённое семейство не перезаписывается.

Проверка расстояний использует габариты отверстий и экспортирует CSV. Для повёрнутых заданий она консервативна, требует уточнения в 3D и не заявляется точной проверкой строительных зазоров.

Для массового изменения откройте **Изменить → Размеры выбранных (штучно или массово)…**. Укажите новый размер или прибавку к текущему. Центры сохраняются. Для выхода за допуск укажите причину. Раскраску можно переключать между разделом и статусом.

## Сводная модель

На вкладке «Обмен» выберите открытый сводный RVT. Модуль копирует туда тела заданий DirectShape. При повторе заменяются прежние копии и убираются тела удалённых заданий. Координаты переносятся без преобразования. Используйте модели с общей системой координат.

## Ограничения и проверки

Касание только краем профиля, неподдержанные фасонные части и овальные профили, острые углы, наклонённые связи и окончание коммуникации внутри основы могут давать замечания без задания.

- Расширение поиска на фасонные части, гибкие/криволинейные коммуникации, касания краем профиля, наклонные основы и MEP из связей.
- Полный процесс межмодельного согласования удаления, общий файл синхронизации и расширенные фильтры передачи параметров.
- Интерфейс заместителей, отдельные допуски по типам и направлениям, просмотр архивной/объединённой истории, разные обозначения в АР/КР.
- Общие параметры ADSK, марки и запись расчётных отметок; развитые отчёты и Excel.
- Полный контроль прямого копирования/удаления средствами Revit и проверка изменений самих вырезающих вставок/основ. Сейчас отслеживаются маркеры заданий.
- Натурные проверки совместной работы, обмена через повёрнутые и зеркальные связи, криволинейных/наклонных основ и ручного размещения на разных шаблонах. Наклонённые связи и ручное размещение на криволинейной стене явно отклоняются.

На больших моделях предстоит проверить ход поиска, перенос в сводный файл и правила склейки в Revit. Протоколы и ограничения приведены в [журнале проверок](https://github.com/Davud77/bp-revit-tools/blob/main/docs/VALIDATION.md).
