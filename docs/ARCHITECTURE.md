# Архитектура

`BotPlus.RT.Application` — единственный `IExternalApplication` в установленном `.addin`. Он загружает четыре сборки из собственных подпапок и вызывает их `OnStartup` последовательно: MCP, Ac2Revit, ОВ, Отверстия. Поэтому порядок панелей не зависит от алфавитного порядка манифестов. При завершении обработчики снимаются в обратном порядке. При ошибке запуска уже начатые модули останавливаются.

Каждый модуль создаёт свою панель на вкладке `BotPlus RT`. Публичные классы команд, идентификаторы кнопок и JSON-контракты сохранены. Семь команд Ac2Revit объединены в одну панель с разделителем.

С версии 1.6.3 хост после модулей создаёт панель «Марки» с собственными командами IndependentTag. Дополнительные DLL и манифесты для неё не требуются. Ac2Revit сохраняет прежний протокол progress callback, добавляя сообщения начала/конца этапов; состояние общего процента переживает автоматическое открытие контрольной точки. Размерные цепи и соответствия маркеров сетки добавлены в manifest как необязательные данные версии схемы 1.0.0. Нативный этап выполняется после создания видов; для проверки опор временно активирует план исходного этажа. Подробности — ANNOTATIONS.md.

MCP использует прежний локальный мост, порт, авторизацию и идентификатор сервера. Сервер поставляется рядом с собственным Node.js. Переименование вкладки не меняет протокол и не требует смены токена.

Ac2Revit поставляется как самостоятельное дерево `modules/ac2revit`: сборка в `dist/Revit2026`, семейства в соседнем `assets`, `tools`, `exporter`, `contracts`, `config` на два уровня выше DLL. Эти относительные пути ожидает исходный транслятор. Python размещён в `runtime/python`, содержит собственную стандартную библиотеку и библиотеки IFC, не использует абсолютный `pyvenv.cfg`. Для разработки поддерживается также `.ifc-env`.

ОВ сохраняет встроенные HTML/JS-ресурсы в HeatLossViewer.dll. Отверстия поставляются в `modules/openings/BotPlus.Openings.dll`: WPF и ExternalEvent, отдельные DataStorage для заданий/настроек, собственные пустотные семейства создаются из установленного шаблона Autodesk во время работы. Все модули работают на .NET 8, предоставленном Revit 2026. Установщик — отдельное self-contained приложение .NET 8 win-x64.

Добавление модуля: отдельная папка в `modules`, ссылка сборки с `ReferenceOutputAssembly=false` в проекте хоста, запись загрузки в `Application.cs`, упаковка ресурсов в `scripts/package.mjs`, автоматические проверки и обновление документации. Дополнительный `.addin` создавать не нужно.
