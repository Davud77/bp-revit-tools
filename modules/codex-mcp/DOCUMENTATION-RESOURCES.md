# Нативные ресурсы оформления

1. Проверьте `revit_ping` и `get_project_info`: активный документ — целевой проект. Для проверки записи используйте копию.
2. Закройте эталон в Revit. `list_documentation_resources` с `sourcePath` читает сохранённый локальный `.rvt` в фоне, возвращает SHA-256, виды ресурсов и страницы до 100 строк. Без пути инструмент читает текущий документ. Эталон не сохраняется. Центральные/локальные совместные проекты не поддерживаются: подготовьте отдельную автономную копию.
3. Подберите `annotationTypes`, `titleBlockTypes`, `viewTemplates` и `filters`. Сопоставляйте класс, категорию, семейство и тип. `sharedParameters` показывает GUID и привязку instance/type с категориями; `copyAllowed=false` означает, что этот ресурс нельзя выбрать для копирования.
4. Передайте `sourcePath`, `sourceSha256` из инвентаризации и уникальные `sourceElementIds` (1–50) в `preview_copy_documentation_resources`. Не используйте ID из другого файла. Предпросмотр создаёт реальные ресурсы в транзакции и отменяет всю группу; временные ID не используйте для следующих операций.
5. По умолчанию `duplicatePolicy="abort"`: совпадение ресурса/семейства или зависимых типов отменяет пакет без модального диалога. `reuseDestination` выбирайте только осознанно: определения целевого проекта сохраняются, эквивалентность не устанавливается и источником не перезаписывается. Результат перечисляет повторно используемые семейства и зависимые типы. Обновление существующих определений пока не поддерживается.
6. Выполните `apply_copy_documentation_resources` с `planId`. Проверяются SHA файла, целевой документ, ревизия и срок плана 10 минут. Пакет атомарен. Используйте `mappings.targetId`/`targetUniqueId` из **apply**, затем перечитайте ресурсы в целевом проекте.
7. Revit переносит нативные зависимости. Проверяйте фильтры шаблонов, графику, GUID и привязки общих параметров, подписи марок и размеры штампа. `definitionEquivalenceVerified=false` и `requiresParameterBindingReview=true` не являются подтверждением соответствия эталону. Отдельное управление привязками/декодирование labels семейств ещё не реализованы.
8. Для текстовых примечаний на существующем А3-листе используйте `preview_finish_sheet` с `notes[].textTypeId` перенесённого TextNoteType; `heightMm` одновременно не указывайте. Нативный тип не изменяется. Выгрузите лист и проверьте результат визуально.

Копируются определения ресурсов, а не размещённые марки, виды модели, листы, подписи/заказчик или расчёты эталона. SelectionFilterElement содержит ID конкретного проекта и не переносится. Поддержка конкретного ресурса зависит от Revit: ошибка API отменяет пакет. Наличие одинакового имени не доказывает одинаковые параметры или геометрию.

API: [CopyElements между документами](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API-MainReference/files/html/b22df8f6-3fa3-e177-ffa5-ba6c639fb3dc.htm), [фоновое открытие документа](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API-MainReference/files/html/14826965-b83e-110c-1466-cc7667def9c8.htm). Семейства и эталонные RVT не входят в публичную поставку.
