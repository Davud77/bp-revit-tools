# MCP для BotPlus RT

Модуль состоит из надстройки Revit (`plugin/`) и сервера Node.js (`server/`). Оба компонента входят в [единый установщик BotPlus RT](../../docs/INSTALLATION.md).

1. В Revit откройте **BotPlus RT → MCP → MCP** и подключите клиент. Ключ подключения — `bp_revit_ai`.
2. Проверьте связь через `revit_ping` и откройте сведения о текущей модели через `get_project_info`.
3. Для записи сначала вызовите `preview_*`, затем передайте полученный `planId` в `apply_*`. При выключенном автоподтверждении подтвердите операцию в Revit.

Сервер использует локальный мост. Токен, снимки и настройки хранятся в `%LOCALAPPDATA%\BP.Revit.AI`. Флаг автоподтверждения переключается на панели MCP и применяется также к операциям удаления и сохранения. Правила предпросмотра и проверки плана действуют в обоих режимах.
