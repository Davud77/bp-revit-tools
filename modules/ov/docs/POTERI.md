# Расчёт Poteri

Используется одна методика из исходной программы Poteri: потери через ограждения и инфильтрацию минус теплопоступления. Отдельная вентиляционная составляющая равна нулю. Старые настройки simple / airChanges / max не переключают методику.

В Revit откройте **BotPlus RT → ОВ → Сведения о проекте**. На вкладке «Проект» задаются общие сведения, температуры, ветер и высоты. На вкладке «Исходные данные» находятся параметры здания, этажей и помещений. Пустое переопределение возвращает наследование: здание → этаж → помещение. U можно задать непосредственно или через R (U = 1 / R). Импорт / экспорт JSON перенесён в это окно. После изменения сохраните RVT и сделайте новую выгрузку.

Параметры конструкций остаются в карточке HTML: слои и однородность, n, ориентация, Gn / f / ai заполнений, четыре зоны пола по грунту. Геометрический помощник зон применяется только к прямоугольным контурам; сложные формы требуют фактических площадей зон. Неизвестные границы блокируют итог помещения, а проёмы учитываются по подтверждённой привязке к помещению. Окна и двери без расчётного помещения исключаются из выгрузки, их количество записывается в предупреждения.

HTML получает параметры из модели и показывает расчёт. Индивидуальные изменения карточки сохраняются в браузере в этой выгрузке; обратно в RVT не записываются. JSON результата скачивается на вкладке «Итоги». Для незаданных параметров применяются значения по умолчанию; их следует проверить до использования результата.

Поле «От земли до первого этажа» сохраняется в сведениях; автоматического определения первого этажа по импортированным уровням нет. Для инфильтрации используется явно заданная отметка земли в координатах модели, чтобы подвал не подменял первый этаж.
