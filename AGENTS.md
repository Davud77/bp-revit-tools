# BotPlus RT

- Рабочий корень — этот репозиторий. Сборка: `build.ps1`; поставка: `build-installer.ps1`; проверки: `scripts/test.ps1`.
- Revit 2026 x64, плагины .NET 8. Общая вкладка `BotPlus RT`, порядок панелей `MCP`, `Ac2Revit`, `ИОС`, `Отверстия`, `Марки`, `Спецификации`, `Настройки`. Отдельные вкладки: `BP ОВ` (сведения о проекте, выгрузка 3D, библиотека, радиаторы), `BP ВК` (пока пустая), `BP ЭОМ и СС`. Исключение — модуль ЭОМ: своя вкладка `BP ЭОМ и СС`, все её панели включаются галочкой «ЭОМ».
- Один EXE устанавливает все модули. Единственный манифест `BotPlus.RT.addin` загружает `BotPlus.RT.Application`. Модули включаются в настройках Revit и запускаются после перезапуска.
- `Входные данные/Первоначальный архив` — физический архив первоначальных рабочих папок с историей и частными данными. Не редактировать там исходники вместо `modules`, не публиковать архив. Прежние пути `local/legacy` и ссылки удалены.
- Входные данные и результаты проверок хранятся физически в `Входные данные` и `Выходные данные`; не создавать совместимые ссылки. .NET-вывод задаётся `Directory.Build.props`.
- Не включать пользовательские RVT/PLN/IFC/PDF, токены, настройки клиентов и Autodesk API в Git или установщик. Четыре штатных RFA/RFT Ac2Revit — разрешённые ресурсы поставки.
- Сохранять контракты MCP. Ключ подключения — `bp_revit_ai`, каталог данных — `%LOCALAPPDATA%/BP.Revit.AI`. Локальные изменения исходного MCP включены в общий импорт.
- Не считать натурные проверки выполненными по одной сборке. Результаты и ограничения описывать в `docs/VALIDATION.md`.
