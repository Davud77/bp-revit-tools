# Как пользоваться BotPlus RT

Revit 2026, вкладка **BotPlus RT**. Панели: **MCP**, **Ac2Revit**, **ОВ**, **Сервис**.

## Кнопки на ленте

| Панель | Кнопка | Что делает |
| --- | --- | --- |
| MCP | MCP | Показывает состояние локального моста и сведения для подключения AI-клиента; позволяет восстановить соединение. |
| MCP | Авто подтверждение | Переключает подтверждение изменений модели. Выключено — перед записью требуется подтверждение в Revit; включено — проверенный план применяется автоматически. |
| Ac2Revit | Archicad → Revit | Открывает экспорт: выбор формата, категорий, IFC-транслятора и нового/текущего проекта Revit. После JSON или комбинированного экспорта запускает сборку. Режим IFC сохраняет файл без сборки. |
| Ac2Revit | Экспорт Archicad | Сохраняет выбранный формат без построения модели. Можно работать без открытого проекта Revit. |
| Ac2Revit | Собрать экспорт | Строит последний успешно подготовленный JSON или комбинированный сеанс в новом либо текущем проекте. Не использует незавершённые сеансы и IFC-only. |
| Ac2Revit | Продолжить сеанс | Выберите `session.json`: восстанавливает завершённые ответы, проверяет источник, экспортирует отсутствующий IFC и продолжает подготовку. Готовый проверенный снимок можно подготовить без Archicad. |
| Ac2Revit | Проверить JSON | Проверяет выбранный `manifest.json` или `pipeline.json` перед импортом; результат записывается в отчёт. |
| Ac2Revit | Импорт JSON | Импортирует выбранный manifest или подготовленный pipeline в открытый проект. Перед построением показывает выбор категорий. |
| Ac2Revit | Папка обмена | Открывает каталог сеансов, файлов экспорта, моделей, журналов и диагностики. |
| ОВ | Выгрузить 3D-модель | Читает помещения и ограждения, сохраняет `building.json` и HTML в `Документы/RevitHeatLossExport`, открывает просмотрщик с расчётом теплопотерь и подбором приборов. |
| Сервис | Сервис | Показывает общую версию BotPlus RT и состав модулей. |

## Перенос из Archicad

1. Откройте сохранённый PLN в Archicad с Tapir. Во время экспорта не редактируйте модель.
2. Нажмите **Archicad → Revit** либо **Экспорт Archicad**. Подключитесь к порту нужного экземпляра Archicad. Если открыто несколько экземпляров, у них разные порты; в окне показаны порт, путь проекта и тип активного окна.
3. Выберите формат и раскройте **Элементы экспорта**. Все категории включены по умолчанию.
4. Для IFC выберите транслятор, сохраняющий координаты и идентичность объектов. Начните экспорт.
5. Итоговые файлы лежат в подпапке `export` нового сеанса. Комбинированный режим также создаёт `pipeline.json` для сборки.

| Формат | Результат | Построение в Revit |
| --- | --- | --- |
| Только JSON | `export/manifest.json`, `mapping.json`; IFC не вызывается | Нативные адаптеры JSON. Сложные формы и несопоставленные семейства могут остаться неподдержанными; результат отражён в отчёте. |
| Только IFC | `export/model.ifc`; подробный JSON и этапы геометрии не подготавливаются | Открывайте IFC штатной командой Revit **Файл → Открыть → IFC**. |
| JSON + IFC | Оба итоговых файла, проверенный исходный снимок и pipeline | JSON передаёт параметры и связи, IFC обеспечивает геометрические адаптеры и проверки. |

Выбор категорий управляет итоговыми файлами и новым построением. Служебный исходный снимок может содержать другие категории: он нужен для координат, хостов, вырезов и проверки восстановления. Ограничение экспорта сохраняется в pipeline и не снимается последующим выбором категорий импорта. Флажки не удаляют ранее созданные объекты Revit.

Если в JSON нужны двери или окна, включите также их стены. Если хост исключён, объект отмечается как неподдержанный; транслятор не придумывает стену. Исключение заполнений из IFC сохраняет исходные вырезы в оставленных стенах. Для помещений важны все исходные ограждения: исключение категорий может нарушить замыкание или проверку площади. Оси в текущем комбинированном режиме извлекаются из IFC; JSON-only не создаёт отсутствующие в JSON оси.

## Продолжение после отказа IFC

Код `-2130313109` — `APIERR_BADWINDOW`: Archicad не допускает сохранение из текущего окна. Начиная с 1.2.0 процесс сам открывает план перед IFC; при таком отказе переключается в 3D и делает один повтор с тем же транслятором и охватом всего проекта. Если повтор не помог, сохраняет диагностику и прекращает сеанс без публикации неполного результата.

Для старого сеанса нажмите **Продолжить сеанс**, выберите его `session.json` и оставьте открытым тот же PLN. Если исходная модель изменилась, начните новый экспорт. При нескольких Archicad проверьте порт — одинаковый путь PLN не означает одинаковое несохранённое состояние двух экземпляров.

## MCP и ОВ

В MCP сначала прочитайте проект через `get_project_info`. Для записи используйте пару `preview_*` → `apply_*` с выданным `planId`. Имя подключения остаётся `weam_revit_ai`; смена надписи панели не требует перенастройки клиента. Локальные данные остаются в `%LOCALAPPDATA%/WEAM.Revit.AI`.

Просмотрщик ОВ работает с пригодными контурами и площадями помещений. Проверяйте предупреждения, исходные температуры, конструкции и параметры приборов. Наличие HTML и расчёта не заменяет инженерную проверку проекта.

Результаты фактических проверок и ограничения: [docs/VALIDATION.md](docs/VALIDATION.md). Следующие работы: [ROADMAP.md](ROADMAP.md).
