# Руководство BotPlus RT

Откройте вкладку **BotPlus RT** в Revit 2026. Все модули входят в общий EXE. Чтобы изменить их состав, откройте **Настройки → Модули**, установите нужные флажки и нажмите «ОК». Снятые панели скрываются сразу. После перезапуска Revit отключённые модули не запускаются, а включённые снова появляются на ленте.

## Перенос из Archicad

1. Сохраните и откройте PLN в Archicad с Tapir. До завершения чтения сохраняйте открытым тот же проект без редактирования.
2. В **BotPlus RT → Ac2Revit** выберите **Archicad → Revit** или **Экспорт Archicad**. При нескольких экземплярах Archicad проверьте порт и путь PLN. Порт Tapir по умолчанию — `19723`.
3. Выберите формат обмена. **JSON** передаёт параметры и доступную геометрию без экспорта IFC. **IFC** сохраняет файл без сборки. **JSON + IFC** использует параметры JSON и проверенные тела IFC. Для IFC выберите транслятор из списка текущего PLN.
4. Для сборки укажите новый или текущий проект Revit. Для нового проекта задайте шаблон, папку и имя RVT. Пустой выбор шаблона означает метрический проект. Существующий RVT при создании новой модели не перезаписывается.
5. В окне «Что переносить» отметьте категории. При импорте заполняющих элементов, проёмов и помещений автоматически включаются необходимые хосты и границы. Снятые категории не считаются пропусками, ранее созданные элементы остаются в модели.
6. Сохраните RVT и проверьте соседние `*.botplus-import.log` и `*.botplus-import.json`. Они фиксируют GUID, вид представления, предупреждения и результаты этапов. Промежуточный отчёт контрольной точки отражает состояние на момент сохранения.

«Рельеф Mesh → Топотело» включён по умолчанию. Для прямого чтения сеток нужна команда Tapir `Get3DGeometryOfElements`, проверенная с Tapir 1.8.0. Для старого снимка без 3D-поверхности выполните новый экспорт. Переносимые цвета и штриховки зависят от исходных данных и выбранного RTE. Помещения проверяются по фактическим границам, высотным привязкам и площади.

### Восстановление сеанса

Если IFC не сохраняется из активного окна Archicad, мастер пробует доступные варианты, например переключение на план или 3D. Если экспорт не восстановился, диагностический сеанс сохраняется отдельно от готовых результатов. Для продолжения выберите его `session.json` и оставьте открытым исходный PLN. Если PLN изменился, начните новый экспорт.

Если не хватает памяти для подготовки большого IFC, дождитесь сохранения проверенного снимка. Закройте Archicad и ненужные модели Revit, затем нажмите «Продолжить подготовку» или выберите «Продолжить сеанс». При наличии проверенного `capture.json` подготовка может работать без Archicad. Храните снимок вместе с файлами `source/raw`, на которые ссылается `gdlReference`. Старый готовый сеанс остаётся доступен для сборки, пока новый не завершён.

## MCP

Подключите клиента через кнопку **MCP** на ленте. Ключ — `bp_revit_ai`, данные — `%LOCALAPPDATA%\BP.Revit.AI`. Начните с `revit_ping` и `get_project_info`. Для записи используйте соответствующую пару `preview_*` → `apply_*` и передайте выданный `planId`.

Через Code Mode можно объединять вызовы. Например, чтобы проверить спецификации, прочитайте проект, пройдите страницы `list_schedules` и получите нужные ячейки через `read_schedule`. Для создания спецификации выберите категорию через `list_schedule_categories`, поля через `list_schedule_fields` или `preview_schedule_fields`, затем вызовите `preview_create_schedule` и `apply_create_schedule`.

## ОВ

Откройте **ОВ → Сведения о проекте** и заполните климат, отметки и исходные данные. Значения наследуются от здания к этажу и помещению. Пустое поле возвращает наследование. Точка и запятая допустимы в числах. Для отдельной конструкции задаются слои, сопротивление или U и расчётные коэффициенты. [Методика Poteri](modules/ov/docs/POTERI.md)

В **Библиотеке** доступны материалы, стены, перекрытия, полы по грунту, окна и двери. Настройте тепловые параметры и отметьте полы по грунту на вкладке «Перекрытия». Для материалов связей переопределения хранятся в текущем проекте.

На вкладке **Радиаторы** настройте график, правила размещения, каталог и нагрузки. Доступны собственные приборы, ручное сопоставление строк PDF, предварительный 3D-подбор и выгрузка JSON/CSV. Нажмите «Сохранить в модели» и сохраните RVT. Результат служит для проверки и последующей расстановки приборов в Revit.

HTML показывает 3D, карточки, итоги и журнал. Для 3D требуется доступ к CDN Three.js. Обычный клик выбирает объект, Ctrl добавляет, Shift снимает выбор, Esc очищает. Таблицы сортируются по заголовкам. В шапке доступны печать в PDF и скачивание расчёта в JSON. Изменения карточек в браузере остаются в этой выгрузке.

Окна и двери без связи с расчётным помещением исключаются из JSON, HTML и подбора. Прочие неприкреплённые вырезы могут оставаться в выгрузке. В тепловом балансе учитываются проёмы с подтверждённой привязкой. Проверьте `openingCoverage`, предупреждения и исходные данные перед использованием итогов.
